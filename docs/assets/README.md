# Recursos visuales

Solo almacenar capturas saneadas o recreadas con datos sintéticos. Antes de añadir una imagen, comprobar que no contiene nombres, códigos de empleados, marca empresarial, URLs internas, usuario de Windows, nombre del archivo original, notificaciones ni otros identificadores.

Capturas previstas:

- recreación sintética del gráfico de evolución;
- recreación sintética del perfil agregado;
- wireframes y capturas propias de AbsenceLens.

## Estado de las referencias recibidas

Las dos capturas de referencia recibidas durante la toma de requisitos no se incorporan a esta carpeta porque todavía contienen información real a nivel de trabajador y métricas del entorno de origen. No deben copiarse, recortarse, cubrirse ni editarse para intentar sanearlas. Cualquier referencia equivalente se creará desde cero con identificadores, fechas, métricas, categorías combinadas y distribuciones completamente sintéticos.

La estructura informativa que debe conservarse está documentada en `docs/09-cobertura-dashboards.md`. La paleta de marca se registrará como tokens autorizados y no como muestras extraídas de estas capturas.
